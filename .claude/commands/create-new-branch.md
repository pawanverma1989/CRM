# create new branch Command

This commands creates a new branch in the git repo.

- Ask for git repo url if not already provided
- Ask for what type of branch you want to create (feature, bugfix etc)
- Ask if we want to create branch from master branch or ask for branch name
- Ask for name of the new branch

Using above information to create a new branch in git repo

## Usage
```
/create-new-branch
```
